# 全阶段验收矩阵

| 阶段 | 核心可演示场景 | 安全/故障测试 | 门禁 |
|---|---|---|---|
| M1 | 一条消息含文本+图表+选择卡 | 非法 Schema、跨用户读取、旧版本 | 协议契约 PASS |
| M2 | 动态注册、懒加载、未知组件 fallback | XSS、非法 URL、任意代码注入 | 渲染安全 PASS |
| M3 | 模型按上下文选组件 | 越权组件、无效结构、降级 | 评测与策略 PASS |
| M4 | SSE 中途断线重连 | 乱序、重复、丢事件、多实例 | 快照一致性 PASS |
| M5 | 选择/跳过/恢复 | 并发提交、幂等冲突、过期、撤权 | 状态机 PASS |
| M6 | 更新图表不重建消息 | 旧 revision、非法 patch、焦点保持 | 更新一致性 PASS |
| M7 | Ask→Plan→Agent 完整交接 | 未审批写入、跨模式越权、重启恢复 | 全链路 UAT PASS |

## 必须留存的验收证据
- Git commit/变更清单；迁移版本；测试命令与结果；接口请求响应；SSE 事件样本；前端录屏；风险清单；回滚步骤。
- 状态仅允许 NOT_STARTED / IN_PROGRESS / CODE_PASS / UAT_PASS / ACCEPTED / BLOCKED；生产就绪另行评审。

## 核心跨阶段测试
1. 同一消息包含多类型 Block，顺序和 ID 稳定。
2. 非法模型输出不能触发脚本执行或写入操作。
3. SSE 重复投递、乱序与重连后快照一致。
4. 用户双击提交仅产生一次有效决策。
5. 旧 revision 更新不覆盖新状态。
6. 未审批 Plan 不能被 UI 提交绕过 Agent 授权。
7. 权限撤销后旧页面操作被后端拒绝。
