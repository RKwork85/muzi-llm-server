## 分档

46 分，档位是不合格。

即使只把实现看成 `2024-11-05` tools 客户端，安全否决项仍然存在。规范规定：有一票否决项时，分数即使达到 80 也不能判生产合格。本结果两者都不满足。

## 一票否决

成立，见 `SECURITY_AUDIT.md`：

- 跨租户：共用 httpx Cookie 罐；stdio 进程对所有用户可见。
- 令牌跨服务转发：授权码和 refresh token 发往未校验的 token 端点。
- 严重 SSRF：服务端跟随 OAuth 元数据中的任意 URL。
