# 授权策略

连接器记录不等于全部工具都可用。工具可用必须同时满足：

- 连接器记录存在，未撤销，未过期。
- 同名工具记录存在，未撤销，未过期。
- 工具名属于当前目录或该用户选中的远程工具。

第一次见到某个已登录用户时，存储会复制当时的 stdio 目录，作为这个用户自己的初始工具集。这和 R1 的登录后目录副本一致。之后目录重新注册不会把新工具自动加给已有用户。

已经在内存里写过的显式授权优先于这份初始复制。因此把某个用户收成空集之后，下一次请求不会把目录再次发还给他，除非存储里已经有他的记录。存储有记录时，以存储为准。

撤销连接器会同时撤销它下面的工具。尚未开始的调用会在执行前再次检查。正在外部服务里执行的副作用不能撤回。
