# 可靠性

- 每次 MCP 调用有自己的超时。超时后记录并抛出，不延长到进度通知。
- 同一个用户最多四个并发 MCP 调用。这是用户级信号量，不是进程级大锁。
- 只有 `idempotent=True` 的读取在第一次失败后重试一次。写入和明确标成非幂等的工具失败即停止。
- 每个连接器有独立熔断器，默认连续 5 次失败后打开 30 秒。打开期间直接拒绝，不再发出调用。
- 会话失效仍沿用 R2.1：HTTP 404 丢弃会话并重新握手一次。工具 RPC 错误不丢弃会话。
- 取消向上传播。等待可以停止，外部已经执行的动作不能回滚。
- 远程连接池和 stdio 会话仍在应用关闭时释放。
