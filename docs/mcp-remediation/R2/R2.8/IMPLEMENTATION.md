# R2.8 不能标成生产就绪

R2.7 的真实环境验收是 BLOCKED。按任务门槛，R2.8 不能宣布生产就绪。下面只记录已经落地、并且有测试的代码行为。

## 调用状态

一次 MCP 调用的审计状态使用这些值：

- `created`
- `authorized`
- `executing`
- `success`
- `failed`
- `cancelled`
- `unknown`

`unknown` 表示请求可能已经送出，但本地没有可靠结果。非幂等超时、非幂等异常，以及写入开始后的取消，都记为 `unknown`，并且不自动重试。幂等读取的第一次超时或失败可以再试一次。

Agent 取消如果在清理时限内等不到工作任务结束，仍把任务记为 `cancelled` 并发出终态事件。之后才回来的成功结果不会改写这个终态。这不表示模型或远程工具里的动作已经被撤回。

`test_deadline_cancel_and_disconnect` 现在通过。墙钟 0.15 秒会得到 `limit_reached` / `AGENT_DEADLINE_EXCEEDED`。阻塞中的运行可以被取消，重复取消仍是 `cancelled`。测试会在结束时放开阻塞线程，避免断言失败后挂住进程。

## 熔断

每个连接器一只熔断器。打开期间拒绝调用。冷却时间到了以后进入半开，只允许一次试探。试探失败会再次打开，成功则关闭。另一个连接器不受影响。

## 指标

进程内额外记录：

- `mcp_authorization_denied_total`
- `mcp_retry_total`
- `mcp_active_calls`
- `mcp_circuit_breaker_state`，值是当前打开的连接器数量

原有的 `mcp_tool_calls_total`、`mcp_tool_call_duration`、`mcp_tool_errors_total` 仍在。这些数在进程内，多实例要各自查看，当前没有外部聚合。没有为此加入 Prometheus。

## 状态边界

| 状态 | 位置 |
| --- | --- |
| 授权、审计、凭证密文 | 数据库。生产环境禁止用内存存储代替 |
| 熔断、计数、活动调用、HTTP 连接池、stdio 进程 | 每个进程自己的内存 |

数据库未升到 `c4a8e2b71f03` 之前，多实例授权一致性还没有真实环境证据。

## 协议

支持的版本仍是 `2025-11-25`、`2025-06-18`、`2025-03-26`、`2024-11-05`。`2026-07-28` 和带后缀的相似字符串会拒绝，不会静默降级。客户端能力仍是空对象。

## 测试

`tests/test_mcp_r27_acceptance.py` 覆盖密钥、轮换、生产启动拒绝、读写重试差异、半开熔断、取消后的未知结果、伪造协议版本，以及压测档位不被标成已跑。截止时间和订阅断开测试已通过。
