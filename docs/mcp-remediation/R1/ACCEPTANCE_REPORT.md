## 仍然存在的限制

- stdio 的显式授权只在当前进程内存里。重新注册后清空。已登录用户下次对话得到的是目录副本，不是持久化的个人窄授权。没有为此改数据库。
- 生产连接会钉住解析后的地址。ASGI 测试不打开套接字，DNS 行为由解析桩和 pinning 单测覆盖。
- 声明支持 RFC 9207 的服务器必须回 `iss`。未声明时，缺少 `iss` 不会被说成已经做了 RFC 9207 校验。
- 自定义令牌加密、协议版本、写工具名称启发式、指标，以及 AgentRuntime 任务循环里的远程 MCP 工具，都不在 R1。
- `test_deadline_cancel_and_disconnect` 在整改前的 HEAD 上就已经因 5 秒模型超时失败。与这三个否决项无关。

## 部署影响

不需要数据库迁移。没有新增第三方依赖。没有把协议改成 2026-07-28。

Notion 当前公开元数据的 issuer 是 `https://mcp.notion.com`，和资源 origin 一致，并且声明支持 `iss`。授权回调需要把这个 `iss` 带回来。
