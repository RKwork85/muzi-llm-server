## 6. 故障恢复

## 7. 已解决的问题

- 生产配置不再在数据库未就绪时悄悄使用内存授权。
- 非幂等 MCP 调用在超时或取消后记为 `unknown`，不自动重试。
- 熔断有半开试探，并且不波及其他连接器。
- Agent 取消在工作任务迟迟不返回时仍进入 `cancelled`，迟到的成功不会覆盖它。
- 截止时间测试不再因为阻塞线程未释放而挂住。
