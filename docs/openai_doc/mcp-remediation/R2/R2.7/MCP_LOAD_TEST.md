# 压力测试

要求的档位：

| 并发 | 时长 | 状态 |
| --- | --- | --- |
| 10 | 10 分钟 | not_run |
| 30 | 30 分钟 | not_run |
| 50 | 30 分钟 | not_run |

`app/mcp/load_probe.py` 可以重复跑一段本地调用，并始终把上面三档标成 `not_run`。本地探针使用进程内的 `run_mcp`，不连接真实 MCP 服务，也不采集生产机器的 CPU、内存和数据库连接池。它不能当作压力测试通过。

目标机器确认资源后，再用真实服务、真实数据库和外部采样重跑这三档。在那之前，压力测试是 BLOCKED。
