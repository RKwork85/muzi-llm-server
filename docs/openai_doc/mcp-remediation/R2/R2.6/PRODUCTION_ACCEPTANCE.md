# R2.6 验收

## 已通过

- R1 三项安全否决保持关闭。
- R2.1 协议矩阵保持不变，没有把 2026-07-28 写成已支持。
- Chat 和 AgentRuntime 使用同一个执行入口，远程工具进入对应用户的任务循环。
- 授权可以按用户、连接器和工具保存，撤销在重启快照后仍然有效。
- 新凭证使用 AES-256-GCM，旧密文仍可读取。
- 日志和审计不保存令牌、Cookie 和参数正文。
- 幂等读取才重试一次，写入不自动重试。
- 相关自动化回归通过。预先存在的 Agent 截止时间用例不记成回归。

## 还不能称为生产部署完成

- 生产进程必须把 `runtime_env` 设为 `production`，并把密钥从外部注入。默认开发配置不能上线。
- `c4a8e2b71f03` 需要在目标 PostgreSQL 上执行。本环境没有跑 `MUZI_DB_TESTS=1`。
- 进程内计数不能替代外部监控。
- 没有真实负载测试。
- 取消不能回滚已经发生的外部副作用。
- 没有实现 2026-07-28 的无状态协议，也没有实现 Resources、Prompts、Sampling 等能力。

结论：R2.2 到 R2.5 的代码验收通过。R2.6 的自动化验收通过，但部署验收未完成。在外部密钥、数据库迁移和目标环境压测完成之前，不把 MCP 称为生产就绪。
