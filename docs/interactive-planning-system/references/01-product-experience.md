# Product and interaction requirements
Goals: conversational progressive planning; compact UI; user agency; continuity across Ask/Plan/Agent.
Defaults: one pivotal question at a time; use prose if no real decision; card only when structured choice is useful; never force selection when free-form answer is better.
Support: single select, multi select, free input, confirmation, plan review, progress, error/retry, optional expandable details.
Users can interrupt, edit prior decision, skip nonessential question, return later, change mode without losing state.
Each interaction shows prompt, brief rationale, options with meaningful descriptions, recommended option only when justified, free-form alternative, and submitted/expired state.
Do not overwhelm with a wizard or giant form. Accessible keyboard focus, screen reader labels, mobile layouts, loading/error/disabled states required.
Success: users can finish a multi-step ambiguous task without retyping confirmed decisions and can inspect/revise before execution.
