## 建议再看的步骤

1. 在当前对话再发一句 Ask。两个助手消息的运行标识应不同。
2. 打开旧消息的「运行详情」，确认不会变成新的服务端 UUID。
3. 刷新额度页，确认没有「请求失败」。

不需要新的运行管理页面。Plan 和 Agent 不在本次验收范围。

## 不应出现

- 详情里的 Token 来自另一轮。
- 只因为有 Token 就把未知的旧运行显示成已完成。
- 未登录还能看到运行。
- 重复打开同一次详情后额度继续增加。
